### Who I Am

I started programming before university, through Harvard's CS50x and CS50P, because I wanted to understand how software really works, not just how to use it. That curiosity pushed me into building things across different areas: IoT hardware, full-stack web apps, machine learning, and developer tools.

I'm now in Year 2 at SLIIT, exploring AI and Data Science, and I build real projects for real users, including a POS system for a working shop. I like going deep on the basics.

### 🚀 Featured Projects

#### 📊 [claude-count-usage](https://github.com/Abdullah-alhar/claude-count-usage) ⭐
A tool that tracks Claude usage and tokens, so you can see where your limits go. Open source (MIT) and starred by other developers.

#### 🏢 [SmartNest — Apartment Sales System](https://github.com/Abdullah-alhar/smartnest-apartment-system)
A group web app for listing, reserving, and selling apartments, with requirements gathered from real stakeholder interviews.

#### 🛒 Shop POS & Management System *(private, client project)*
A real system for a phone accessories shop (wholesale + retail): point of sale, invoices, stock tracking, and reorder search.

#### 🔬 Malaria Cell Image Classification
A CNN that classifies blood cell images as infected or healthy, trained on the NIH malaria dataset.

#### 🏥 Hospital Appointment System
A Spring Boot app for booking and managing appointments, using Microsoft SQL Server running in Docker.

#### 🎓 Student Course Registration System
A full MVC web app with three roles (Admin, Student, Lecturer): course management, scheduling, room assignments, payment uploads, and a custom file-based storage layer with no external database.

#### 🌿 IoT Projects — Greenhouse Automation & Smart Gate
Arduino systems built in my first year: one automates a greenhouse using temperature, humidity, and soil sensors; the other controls gate access with sensor detection.
